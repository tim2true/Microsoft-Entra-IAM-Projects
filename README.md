# Microsoft Entra IAM Projects

# The Overview: 📜

The goal of this repository is to demonstrate hands-on experience with Microsoft Entra ID, document real-world IAM use cases, and highlight the technical skills required to support identity security, access administration, compliance, and risk reduction in enterprise environments.

Key areas covered:

• Identity and user lifecycle management

• Role-Based Access Control (RBAC) and least-privilege principles

• Multi-Factor Authentication (MFA) and Conditional Access

• Privileged Identity Management (PIM)

• Identity governance and access reviews

• Security monitoring, troubleshooting, and access auditing

• IAM documentation and best practices
