# Project 7: PowerShell and Microsoft Graph Automation

This project builds up on the first 6 Entra projects in this repository, demonstrating that we can automate identity administration instead of relying entirely on manual portal operations. We'll use the same group and identities. 

Our scenario is that the company's IT department wants to automate employee onboarding, manage security-group membership, identify disabled or inactive accounts, and produce audit-friendly reports.

# Task 1: Install PowerShell and Microsoft Graph

Since I'm a MacBook user, if you're on a Windows operating system, you should already have PowerShell. For those, that are on other operating systems like I am, take the time now to use the internet and search for steps to download PowerShell and Microsoft Graph.

For fellow MacBook users, the steps will be in this [Microsoft Learn link](https://learn.microsoft.com/en-us/powershell/scripting/install/install-powershell-on-macos?view=powershell-7.6&utm_source=chatgpt.com#download-and-install-the-package-file) here. 

Once you've downloaded and installed PowerShell, you'll need a command to go ahead and install Microsoft Graph.
